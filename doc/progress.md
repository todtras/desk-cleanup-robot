### 겪은 문제와 해결
- **카메라 두 대를 같은 USB 허브에 꽂으면 동시에 안 열림** → wrist를 노트북 본체 포트로
- **카메라 번호(1/2)가 실행할 때마다 바뀜** (같은 모델 두 대) → 녹화 시작마다 rerun 창에서 head/wrist 확인
  - `pick_bottle` 5~30번이 head/wrist 뒤바뀐 채 저장됨 → 영상 파일·통계 맞바꿔 복구 (원본 `_backup_pick_bottle`)
- **대시보드가 켜져 있으면 카메라를 잡고 있어 녹화 실패** → 녹화 전 Ctrl+C로 종료
- **구글 드라이브가 바탕화면을 미러링** → 녹화 중 "액세스 거부". 녹화 동안 드라이브 일시중지
- yaml에 한글이 있으면 lerobot이 cp949로 읽다가 실패 → yaml은 영어만
- PowerShell에서 카메라 인자에 `\"` 쓰면 깨짐 → `'{head: {type: opencv, ...}}'` 처럼 따옴표 없이
- 녹화 종료 시 그리퍼(id 6) Overload error → 팔로워 전원 재투입으로 해제. 펜처럼 얇은 물체는 꽉 쥐지 않기

**결론: 위치 기반 보정은 시도했으나 다음 한계로 주 방법에서 제외 → 정책 자체를 고치는 방법(DAgger 교정 + 성공 시도 재학습)으로 결정**
1. **녹화 기준과 실물 차이가 큼**: 녹화 화면으로 잰 오차(물병 로봇 왼쪽 -3도)와 실물 오차(-14도)가 5배 차이 → 녹화 데이터로 보정식을 만들 수 없고 위치마다 실물로 다시 재야 함
2. **보정이 비선형으로 증폭**: 정책이 중간에 자기 자세를 다시 보고 계획해서 더한 보정을 약 3배로 키움 (+3.1도 → 끝 pan 약 10도). `n_action_steps`에 따라서도 달라짐
3. **흔들림과 구분이 어려움**: 정책·시연 모두 같은 위치에서 ±3도 흩어짐 → 적은 시도로 맞추면 우연을 버릇으로 착각 (가운데 '5px 딱 맞음'이 그 경우, 측정에선 보정 없이 3/3)
4. **앞뒤는 관절 여러 개가 같이 움직임**: 어깨·팔꿈치를 같이 바꾸면 높이·접근 각도까지 바뀌어 새 실패(앞뒤) 발생
5. **확장성이 없음**: 물체 × 체크포인트마다 따로 맞춰야 하고, 재학습하면 처음부터 다시
- 남는 것: 보정 측정으로 **어디가 약한지**(양 끝, 가까운 줄)와 오차가 **위치별 편향**이라는 근거를 얻음 → DAgger·시연 보강을 어디에 집중할지 정하는 데 사용
- 코드(`--calib`, `PAN_FIT`, `calib.json`)는 남겨 둠. 키가 (물체, 체크포인트)라 새 체크포인트(3만~5만)에는 자동으로 적용되지 않음 → 다음 주 측정은 보정 없는 상태가 기본
