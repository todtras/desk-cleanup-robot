# 로봇팔 + 카메라 기반 데스크 정리 프로젝트 기획서 (초안)

## 1. 프로젝트 개요
- **프로젝트명(가안)**: AI 기반 데스크 오브젝트 인식·분류 정리 로봇
- **한 줄 소개**: 카메라로 책상 위 물건(필기구, 컵 등)을 인식·분류하고, 로봇팔이 지정된 수거함으로 옮겨 담는 시스템
- **팀 구성**: 팀장 1명(대면) + 팀원 2명(비대면 개발), 총 2~3인
- **개발 기간**: 총 80시간 (주 1회 8시간 기준, 약 10주)
- **개발 환경**: A4000 GPU 1장 (팀 공용)
- **개발 방식**: AI 코딩 에이전트를 활용한 바이브코딩 중심 개발

## 2. 배경 및 목적
- 피지컬 AI 기업 인턴십 프로젝트로, 단순 제어가 아닌 **AI 인식/판단 역량**이 드러나는 주제가 요구됨
- 로봇팔 + 카메라 조합에서 "물건을 보고 이해해서 처리한다"는 자비스형 컨셉에 맞춰, 고정된 규칙이 아닌 학습 기반 인식을 중심에 둠

## 3. 프로젝트 목표
1. 책상 위 임의의 물건을 카메라로 탐지하고 카테고리를 분류한다
2. 분류 결과에 따라 로봇팔이 해당 물건을 파지하여 지정된 수거함에 넣는다
3. 파지 실패를 강화학습 기반으로 보정하여 반복 시도 성공률을 개선한다
4. 사전에 정의되지 않은 물건에도 어느 정도 대응 가능한(오픈 어휘 인식) 구조를 목표로 한다 — 단순 고정 클래스 분류보다 난이도/AI 비중을 높이기 위함

## 4. 핵심 기능 (범위)
| 단계 | 기능 | 비고 |
|---|---|---|
| 1 | 객체 탐지 (Object Detection) | 책상 위 물체 위치/바운딩박스 검출 |
| 2 | 객체 분류/인식 | 필기구 / 컵 / 기타 등 카테고리 판별. 가능하면 open-vocabulary(VLM 기반)로 미등록 물체도 대응 |
| 3 | 좌표 변환 | 카메라 좌표 → 로봇팔 좌표계 변환 (캘리브레이션) |
| 4 | 파지(Grasping) | 분류 결과 기반 파지 자세 계산 및 실행 |
| 5 | 분류함 이동 | 물체 카테고리별 지정된 수거함으로 이동 후 릴리즈 |
| 6 | 파지 실패 보정 (강화학습) | 파지 성공/실패 판정 후, 강화학습 정책으로 파지 자세·접근 방향을 보정해 재시도. 시뮬레이션에서 선학습 후 실물 적용 |

## 5. 예상 기술 스택 / 키워드
- **인식**: Object Detection(YOLO 계열), 필요시 Open-Vocabulary Detection / VLM(예: Grounding DINO, CLIP 등)
- **제어**: 좌표 캘리브레이션(Eye-in-hand/Eye-to-hand), 역기구학 기반 파지 자세 계산
- **강화학습**: 파지 실패 보정 정책 학습. 시뮬레이터(Isaac Sim / PyBullet 등)에서 선학습 후 실물 전이
- **기타**: OCR(물체 표면 텍스트 활용 시), ROS/제어 프레임워크(로봇팔 사양에 따라 결정)
- **개발 도구**: AI 코딩 에이전트(Claude Code 등)를 활용한 바이브코딩

## 5-1. AI 에이전트 활용 개발 방식
- 구현 코드 작성은 AI 에이전트에 위임하고, 팀은 **인터페이스 설계 / 검증 / 실물 튜닝**에 시간을 집중
- 착수 시점에 모듈 간 입출력 규약(탐지 결과 포맷, 좌표계 정의, 파지 명령 스키마)을 먼저 문서로 고정 → 비대면 팀원도 각자 모듈을 독립 개발 가능
- 에이전트가 생성한 코드는 반드시 테스트 코드와 실물/시뮬레이션 검증을 거쳐 병합
- 기대 효과: 구현 시간 단축분을 **실물 테스트와 강화학습 실험 시간으로 재배분**

## 6. 팀 역할 분담 (안)
- **팀장 (대면)**: 로봇팔 제어, 좌표 캘리브레이션, 파지 실행, 통합/디버깅, 실물 테스트
- **팀원 A (비대면)**: 객체 탐지/분류 모델 개발 및 학습
- **팀원 B (비대면)**: 시뮬레이션 환경 구축 및 파지 보정 강화학습, 성능 평가, 발표자료 보조
- ※ A4000 1장을 팀이 공유하므로 인식 모델 학습과 강화학습 학습 시간대를 사전에 분배 (예: 요일/시간대 분할, 학습 잡 큐 운영)
- ※ 팀원 대면 참여 여부는 협의 중 — 확정되지 않은 참고 사항

## 7. 대략적 일정 (총 80시간)
AI 에이전트를 활용해 구현 단계(인식 모델·파이프라인·제어 코드)를 압축하고, 확보한 시간을 강화학습 실험과 실물 튜닝에 배분함.

| 주차 | 시간 | 내용 |
|---|---|---|
| 1주 | 8h | 주제 확정, 환경 세팅, 모듈 간 인터페이스 규약 정의, 에이전트 개발 환경(리포·규칙 문서) 구축, 데이터 수집 시작 |
| 2주 | 8h | 객체 탐지/분류 베이스라인 구축, 카메라-로봇팔 캘리브레이션 |
| 3주 | 8h | 인식 성능 개선, 인식 결과 → 로봇 좌표 변환 파이프라인 연동 |
| 4주 | 8h | 파지 로직 구현 및 1차 실물 테스트, 파지 성공/실패 판정 기준 정의 |
| 5주 | 8h | 시뮬레이션 환경 구축, 파지 실패 케이스 데이터 수집 |
| 6~7주 | 16h | 강화학습 기반 파지 보정 정책 학습 및 실물 적용·튜닝 |
| 8주 | 8h | 전체 파이프라인 통합 테스트, 실패 케이스 보완 |
| 9주 | 8h | 성능 지표 측정(인식 정확도·파지 성공률·보정 전후 비교), 시연 시나리오 정리, 여유 시 open-vocabulary 확장 |
| 10주 | 8h | 발표자료 준비, 최종 리허설 |

## 8. 기대 효과
- 인식(AI)과 제어(로봇팔)를 결합한 엔드투엔드 파이프라인 구축 경험
- 고정 클래스가 아닌 유연한 물체 인식 구조를 통해 실제 피지컬 AI 제품에 가까운 문제 해결 경험
- 인식 실패/파지 실패 등 실패 케이스 분석을 통한 강화학습·데이터 보강 등 후속 연구 방향 도출 가능

## 9. 리스크 및 고려사항
- 80시간 내 강화학습까지 정규 단계로 수행해야 하므로, open-vocabulary 확장은 후순위로 두고 일정 여유에 따라 결정
- GPU가 A4000 1장뿐이라 인식 모델 학습과 강화학습이 자원 경합 → 학습 시간대 분배 및 실험 규모(이미지 해상도, 스텝 수) 사전 조정 필요
- 시뮬레이션에서 학습한 파지 정책이 실물에서 그대로 동작하지 않는 sim-to-real 격차 존재 → 실물 데이터 기반 미세조정 시간을 6~7주차에 함께 확보
- 원격 팀원의 실물 로봇 접근이 어려우므로, 시뮬레이션 환경 또는 수집된 데이터/영상 기반으로 원격 개발이 가능하도록 초기에 인터페이스(입출력 포맷) 합의 필요
- 카메라-로봇팔 좌표 캘리브레이션 정확도가 파지 성공률에 큰 영향 → 초반에 충분한 시간 배정 필요
- 바이브코딩 특성상 코드 이해도가 낮아질 수 있음 → 모듈 경계와 테스트를 명확히 하고, 주차별로 팀원이 직접 코드 리뷰하는 시간 확보
