# 라벨링 가이드 (YOLO 객체 탐지 데이터셋)

## 1. 작업 방법
- 받은 폴더의 이미지에 **바운딩박스**를 그리고 클래스를 지정한다.
- 도구는 **Roboflow**를 사용한다 (아래 7번 설정 참고). 내보내기 형식은 `YOLO`.
- 클래스 번호는 아래 표 그대로 (Roboflow가 알파벳 순으로 자동 정렬하는 순서와 같다).
- 이미지 파일명은 바꾸지 않는다 (`영상명_프레임번호.jpg`). 라벨 파일 이름은 이미지와 같아야 한다.

## 2. 클래스

| id | 클래스 | 포함 | 수거함 |
|---|---|---|---|
| 0 | bottle | 형태가 온전한 물병/페트병 | 쓰레기 |
| 1 | eraser | 지우개 | 필기구 |
| 2 | paper | **구겨진 종이만** (쓰레기). 펼쳐진 종이/서류는 라벨링하지 않음 | 쓰레기 |
| 3 | pen | 볼펜, 샤프, 마커 등 가늘고 긴 필기구 | 필기구 |
| 4 | stapler | 스테이플러 | 사무용품 |
| 5 | tape | 테이프(롤, 디스펜서 포함) | 사무용품 |
| 6 | vinyl | 비닐, 포장 봉지, **찌그러진/구겨진 투명 페트병** | 쓰레기 |

※ 수거함 분류는 코드에서 처리하므로 라벨링에는 신경 쓰지 않는다. **위 7개만 라벨링한다.**

## 3. 박스 그리는 규칙
1. **물체에 딱 맞게**: 보이는 부분 전체를 감싸되 여백 최소. 그림자는 포함하지 않는다.
2. **물체 하나당 박스 하나.** 겹쳐 있어도 각각 따로 그린다.
3. **일부가 가려진 경우**: 보이는 부분만 박스로 그린다. 보이는 면적이 대략 **20% 미만**이면 라벨링하지 않는다.
4. **화면 가장자리에 잘린 물체**: 보이는 부분이 절반 이상이면 라벨링, 아니면 생략.
5. **펜 뚜껑/펜+뚜껑이 분리된 경우**: 각각 pen으로 박스.
6. **목록에 없는 물체**(휴대폰, 열쇠 등)는 **라벨링하지 않는다.** 클래스를 새로 만들지 않는다.
7. **누락 없이**: 한 이미지 안의 7개 클래스 물체는 전부 박스를 친다. 빠뜨린 물체는 모델이 "배경"으로 학습해서 성능이 떨어진다.

## 4. 애매한 경우 (기준 통일)
| 상황 | 처리 |
|---|---|
| 뚜껑만 있는 병 | 라벨링하지 않음 |
| 비닐이 병을 감싸고 있음 | 안의 물체(bottle)만 |
| 비닐이 구겨져 경계가 불분명 | 눈에 보이는 덩어리 전체를 하나의 vinyl 박스 |
| 펼쳐진 종이, 서류, 메모지 | 라벨링하지 않음 (쓰레기 아님) |
| 판단이 안 서는 물체/이미지 | **그 이미지는 라벨링하지 말고 건너뛴다.** 파일명과 이유를 `애매한.txt`에 적어서 팀장에게 전달 (판단은 팀장이 한다) |

## 5. 제출 전 체크
- [ ] 이미지 수와 라벨 txt 수가 일치 (물체가 없는 이미지는 **빈 txt**가 있어도 정상)
- [ ] 클래스 id가 0~6 범위 안
- [ ] 아무 박스도 없는 이미지를 훑어보고 빠뜨린 물체가 없는지 확인
- [ ] 박스가 물체에서 눈에 띄게 어긋난 것 없음 (몇 장 무작위로 열어서 확인)

## 6. 분배
- 이미지는 영상 단위로 나눠서 배분 (같은 영상의 프레임은 한 사람이 담당).
- **val 폴더(검증용)는 팀장이 직접 검수한다.**

## 7. Roboflow 설정 (팀장 기준)
- 프로젝트 타입: Object Detection. 클래스 7개를 등록하면 알파벳 순(bottle, eraser, paper, pen, stapler, tape, vinyl)으로 자동 정렬되며, 위 표의 번호와 같다.
- **train/val은 영상 단위로 직접 지정**한다. 자동 무작위 분할을 쓰면 같은 영상의 프레임이 양쪽에 섞여 검증 점수가 부풀려진다.
- 버전 생성 시 **Resize와 Augmentation은 넣지 않는다.** (Resize 기본값은 정사각형으로 늘려서 이미지가 왜곡됨. 증강은 학습 때 Ultralytics가 처리)
- 내보내기 후 `data.yaml`의 `names` 순서가 위 클래스 번호와 같은지 확인한다.
- `애매한.txt`에 적힌 이미지는 라벨링 없이 그대로 두면 "배경(물체 없음)"으로 학습되므로, 내보내기 전에 **데이터셋에서 제외하거나 팀장이 직접 라벨링**한다.
