버전·옵션별 결과를 한곳에 모은 문서. 원본은 `doc/results/`.
로봇 시도는 `dev/outputs/run_log.csv`에 자동으로 쌓이고(이 폴더는 git 제외), 실험이 끝날 때마다 `doc/results/`로 복사하고 여기 표에 추가한다.

**해석할 때 주의**
- 오프라인 오차는 학습에 쓴 녹화로 잰 값이라 과적합을 잡지 못한다. 10/30 물병 로봇 왼쪽에서 실물 오차(-14도)가 녹화 기준(-3도)의 약 5배였다.
- 위치당 3~5회 결과는 표본이 작아 경향만 본다.
- 위치 구간(head 화면 x): 로봇 오른쪽 x<250, 가운데 250~420, 로봇 왼쪽 x>420.
