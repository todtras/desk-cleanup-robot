# YOLO 학습 가이드 (팀원용, 코랩)

이번 목표: **기준선(base) 학습을 한 번 돌리고, 결과를 확인해서 약한 클래스를 정리한다.**

## 준비물
- `dataset.zip` (팀장이 전달한 Roboflow 데이터셋 zip, **압축 풀지 말고 그대로**)
- 코랩 노트북: https://colab.research.google.com/github/todtras/desk-cleanup-robot/blob/main/dev/scripts/colab_train.ipynb
  (안 열리면 GitHub의 `dev/scripts/colab_train.ipynb`를 내려받아 코랩에 업로드)

## 단계

1. **zip을 내 구글 드라이브에 업로드**
   예: `내 드라이브/yolo/dataset.zip`

2. **노트북 열기**
   위 링크로 열거나 파일을 업로드한다.

3. **GPU 켜기**
   상단 메뉴 `런타임 > 런타임 유형 변경 > T4 GPU` 선택 후 저장.

4. **설정 셀(두 번째 코드 셀) 수정**
   ```python
   DATASET_ZIP = "/content/drive/MyDrive/yolo/dataset.zip"   # 1번에서 올린 경로
   SAVE_DIR    = "/content/drive/MyDrive/yolo_results_이름"   # 결과 저장 폴더 (본인 이름으로 구분)
   EPOCHS      = 100
   EXPERIMENTS = [
       ("base", ""),      # 이번주는 base 하나만
   ]
   ```
   - 경로 앞의 `/content/drive/MyDrive/`가 "내 드라이브"에 해당한다.
   - `EXPERIMENTS`는 이번주에는 `("base", "")` **하나만** 남긴다.

5. **위에서부터 순서대로 셀 실행**
   - 첫 셀에서 드라이브 연결 허용 창이 뜨면 허용한다.
   - 학습 셀은 시간이 걸린다. 진행 로그가 올라가는지 확인한다.

6. **끝나면 결과 확인** (드라이브 `SAVE_DIR` 폴더)
   ```
   runs/desk/base/weights/best.pt        ← 최종 모델
   runs/desk/base/results.png            ← 학습 곡선
   runs/desk/base/confusion_matrix.png   ← 클래스 혼동
   runs/desk/base_val/                   ← val 예측 이미지
   results.csv                           ← 점수 표 (mAP50, mAP50-95, 클래스별)
   ```

7. **팀장에게 전달**
   - `best.pt`, `results.csv`, `results.png`, `confusion_matrix.png`
   - 간단한 의견: 어떤 클래스가 약한지, 혼동 행렬에서 어떤 클래스끼리 헷갈리는지

## 자주 막히는 곳
| 증상 | 해결 |
|---|---|
| `data.yaml을 찾지 못했거나 여러 개` | zip 안에 폴더가 중복돼 있을 수 있음. 팀장에게 알리기 |
| 드라이브 경로 오류(`No such file`) | 경로의 `MyDrive/` 뒤를 실제 업로드한 위치로 수정 |
| 학습 중 세션이 끊김 | 다시 연결해서 셀을 처음부터 실행 (결과는 실험마다 드라이브에 저장됨) |
| GPU가 안 잡힘 | 3번 다시 확인. 무료 사용량이 끝났으면 잠시 후 재시도 |

## 주의
- 데이터셋 zip을 수정하거나 다시 압축하지 말 것 (팀 전체가 같은 데이터를 써야 비교 가능).
- 이번주 `EXPERIMENTS`는 `base`만. 증강 값은 다다음주에 바꿔 본다.
- 이미지에 사람이 일부 찍혀 있으니 zip을 외부에 공유하지 말 것.
